# V85 Model Lab: showcase page

This repo holds only the built showcase page for **V85 Model Lab**, a project that estimates every horse's chance of
winning in ATG's V85 (Swedish trotting), compares it with how the crowd bets, and is tested like a trading model:
walk-forward over a full year, point-in-time features, and a 95 % range on every number.

- **Showcase page:** https://sebastianhinze.github.io/v85-lab/
- **Interactive Model Lab:** https://v85-lab.streamlit.app (it may take a few seconds to wake up)

The page is generated by `make site` in the project's main repository, which is private for now. The code and a case
study go public in Phase 6 (March 2027). The page shows only derived numbers, no raw race data. Nothing here is
betting advice.

Made by Sebastian Hinze, MSc student in Computer Science (cybersecurity and mathematical statistics) at KTH.
